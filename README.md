# Chapter 范例数据库使用说明

## 这个数据库是做什么的

这是一套从旅行视频抽帧素材中整理出的 **Day—Chapter 叙事范例数据库**。它把一天的旅行影像拆分为若干连续章节，并为每个层级保存标题、简介、封面、图片顺序、拍摄时间和图片备注。

它适合用于：

- 查看一段旅行经历如何从完整的一天拆分成多个 Chapter；
- 参考 Chapter 的标题、简介、封面选择和图片编排方式；
- 按时间顺序理解旅行过程与场景变化；
- 比较同一段视频在不同抽帧偏移组下形成的图片素材；
- 为旅行故事、用户旅程、内容策划或影像整理工作提供范例。

查看器只负责浏览，不会修改数据库中的文件。

## 快速开始

建议使用最新版 **Chrome** 或 **Microsoft Edge**。

1. 保持本文件夹及其内部结构不变。
2. 双击打开 `Chapter范例查看器.html`。
3. 点击页面中的 **“选择 Day 根目录”**。
4. 在文件选择窗口中，选择当前整个 `Chapter范例查看包_20261026` 文件夹。
5. 浏览器询问目录读取权限时，选择允许。
6. 页面会自动读取本文件夹内的全部 Day 数据。

首次选择后，浏览器通常会记住这个目录。以后再次打开查看器时会尝试自动载入；如果浏览器清除了权限，只需重新选择一次根目录。

## 怎么看这个数据库

### 1. Day 区域

页面顶部展示当前 Day 的：

- Day 标题和完整简介；
- 当前偏移组；
- Chapter 数量和图片数量；
- 当前 Chapter 对应的头图。

如果数据库中有多个 Day，可以通过 **“选择 DAY”** 一栏切换。每个按钮下方会标出该 Day 所属的偏移组。

### 2. Chapter 列表

页面左侧按照叙事顺序列出当前 Day 的所有 Chapter。每个 Chapter 包含：

- Chapter 封面；
- 标题；
- 起始时间；
- 图片数量。

点击任意 Chapter，即可查看该章节的完整内容。

### 3. Chapter 内容

Chapter 页面会显示：

- Chapter 标题和简介；
- 内容标签；
- 当前偏移组对应的 Chapter 封面；
- 按视频时间和整理顺序排列的全部图片；
- 每张图片的时间信息和叙事备注。

点击图片可以放大查看，并再次阅读图片备注。

## 数据中的几个概念

### Day

一次完整的日程或旅行经历，是数据库中的最高层级。一个 Day 可以包含多个 Chapter。

### Chapter

Day 中具有独立场景、行动或叙事意义的一段经历，例如出发、登山、穿越树林、抵达山顶和进入营地。

### 偏移组

视频抽帧时采用的时间偏移。不同偏移组会从同一视频中抽取不同时间点的画面，因此同一个 Chapter 在不同偏移组中可以拥有不同的图片和封面。

### 图片备注

对画面内容及其在旅程中的叙事作用所作的简短描述。备注显示在图片下方，也会出现在图片放大窗口中。

## 文件夹结构

```text
Chapter范例查看包_20261026/
├─ Chapter范例查看器.html
├─ README.md
├─ 国家公园的登山徒步_偏移为0组_.../
│  ├─ 整理结果.json
│  └─ Day 与 Chapter 图片目录
└─ 国家公园徒步（偏移80s）_偏移为80组_.../
   ├─ 整理结果.json
   └─ Day 与 Chapter 图片目录
```

`整理结果.json` 保存 Day、Chapter、标题、简介、标签、封面关系、图片顺序和备注等结构化信息；各图片目录保存对应的实际图片文件。查看器会自动把两者匹配起来。

请不要单独移动 `整理结果.json`，也不要改变各 Day 文件夹内部的编号目录和图片文件名，否则图片可能无法与文字信息对应。

## 如何加入新的 Day 数据

收到新的同格式导出文件夹后：

1. 把整个新 Day 文件夹复制到当前根目录，与已有 Day 文件夹放在同一层。
2. 不要拆散或修改新文件夹的内部结构。
3. 如果查看器已经打开，点击页面顶部的 **“刷新目录”**。
4. 新 Day 会自动出现在 Day 切换栏中。

新文件夹只要包含平台导出的 `整理结果.json` 和相应图片目录，就可以被自动识别，不需要修改 HTML。

## 常见问题

### 打开 HTML 后没有显示内容

查看器不能在未经允许的情况下直接读取电脑文件。请点击“选择 Day 根目录”，并选择包含所有 Day 文件夹的最外层目录。

### 只显示了一个 Day

请确认选择的是所有 Day 文件夹共同所在的根目录，而不是其中某一个 Day 文件夹。然后点击“刷新目录”。

### 图片显示为空或提示图片缺失

通常是 Day 文件夹内部的图片被移动、删除或重命名。请恢复原始导出目录结构，再重新选择根目录。

### 新增文件夹后没有出现

点击“刷新目录”。如果浏览器目录权限已经失效，请重新点击“选择 Day 根目录”。

### 浏览器无法选择目录

请改用最新版 Chrome 或 Microsoft Edge。部分浏览器不支持保存本地目录授权，但仍可通过文件夹选择方式读取数据。

## 数据与隐私

查看器是一个独立的本地 HTML 文件。所有 JSON 和图片都只在当前浏览器中读取，不会上传到服务器，也不需要联网。
