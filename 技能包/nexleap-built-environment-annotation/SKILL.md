# 人工环境游览素材标注

目标是让读者既能顺着 Chapter 看懂**去了哪里、怎样走过去**，也能在每章的风貌组里找到**画面真正呈现的街道、建筑、设施或活动**，最后由少量终选图组成可用的行程叙述。以本次素材和用户当前的手工标注为准；悉尼、东京案例只用来校准判断，不预设章数、组数或终选比例。

为新素材建风貌组前，浏览下方候选清单，只选素材里实际出现且能区分的主题。首次为一段城市或建筑游览全量建章、建组，或遇到“该合并还是拆开”的争议时，读[人工环境标注判例](references/人工环境标注判例.md)。需要核对用户后续修改时，也读其中的比对口径。处理 Chapter Tag 时读[Tag 自建库方案](references/Tag自建库方案.md)。

## 先还原行程

- 核对素材来源、偏移量、总张数、平台已有 Day／Chapter／风貌组、状态、封面和用户已改内容。按**原片真实时间**浏览全量抽帧和相邻镜头，写出一条地点顺序；不能只看文件名、缩略图或一张代表图。若平台时间与原视频章节、片段起点不符，先校正时间解释再分章；不要把另一偏移组的状态机械复制到本组。
- 地点名从用户已有标注、原视频可信的章节说明、画面中可辨认的标识等证据确认；必要时再查可靠地点资料。精确名称存疑时用可证实的较宽名称，如“神社”“商店街”，不凭外观猜测具体地点。辨别片头预览、插播、片尾宣传与实际步行；非行程画面可不进入行程 Chapter，也不为其硬造风貌组。保留其图片和已有人工作出的状态决定。

## Chapter：连续时间内的一段地点行程

1. 先以**地点或连续游览段**定边界，再用时间校验。一个街区内从地标走向相邻街巷，或同一地点白天走到夜景，可以仍是一章；真正进入另一个地点或路线阶段时再开新章。不要因镜头、风貌组、昼夜、视频小标题或短暂转角变化频繁拆章。去到同一地点后又离开、稍后返回，也不能把两段跨时间的镜头塞回同一章。
2. chapter的地点名称，应调用能力尽量识别素材的地点名称，如悉尼歌剧院、圣母大教堂、纽约中央公园、歌舞伎町等具体地名，并使用英文的专有词汇进行命名。
3. Chapter 标题写可核实的地点和行进关系，例如“从……走到……”“沿……走向……”“漫步……”。标题不能只写笼统的“城市街景”；一章含多个相邻地点时，用自然的路线表达它们的关系。Day 简介概括起点、主要节点与终点。
4. Chapter 简介用约两句自然中文：先写这一段可见的人、建筑、摊位、道路或光线，再写人如何沿街道、步道或水岸前行，以及场景怎样接续。让文案有画面和移动方向，避免地名清单、重复标题和未经画面支持的情绪形容。可参考用户给出的写法：“人流汇入老街与棚下市集，摊位、露天餐桌和临街建筑连成一片。沿着热闹的街巷继续前行，市集生活与港口气息在这里交织。”
5. 对实际行程按时间排序；完整标注时每张实际行程图**恰好归一个 Chapter**，同章图片按原片时间排列。相邻章必须满足**前一章最晚时间早于后一章最早时间**，不得有时间交叉或回跳。抽帧之间可以有时间空档，不必伪造连续秒数。发现一张图落在后一章时间段之前，应先检查地点和时间证据，再修正边界与归属。
6. chapter的封面必须来自该张的终选图中最能够代表标题地点视觉特征、且图片质量最高的图像

## 风貌组：章内可辨认的画面主体

- 风貌组比 Chapter 更细，但以**稳定的地点、主角或活动场景**为单位，不是每隔几分钟建一组。先逐张判断画面主体，再决定组边界：同一商街的摊位、招牌、行人和夜间街面可以合组。街道、历史建筑、喷泉、电车、滑板场、公共艺术、游船、夜樱步道和晴空塔等主体明显不同的画面应能分开。仅在背景中出现的地标，不自动决定归组。
- 判断是否拆组时问：**两组能否用不同的画面主体或明确地点解释？合并后是否仍能准确命名，且能找到各自独立的终选？** 若差别只在入口／出口、远近、昼夜、少量招牌或相邻时间，通常并组。若主体转为独立设施、交通工具、艺术品或活动，即使只有一张，也可单列。组可收录同章内不相邻的镜头；不能跨 Chapter 合并后破坏时间边界。
- 组名短而具体，优先写眼前主体，如“商业街”“滑板场”“夜樱步道”“晴空塔”。Chapter 已明确地点时，不在每个组名前重复该地名；只有专名能区分街道、设施或水域时才写入，如“MIYASHITA PARK的商业街”“隅田川上的游船”。名称必须覆盖组内全部画面，不用宽泛并列词掩盖混组，使用模型能力辨认主体是否属于有名的景点或标志性建筑物、构筑物、艺术品，若能识别，则精确命名，不凭未经核实的地名命名。
- 对全量行程，给每张图片明确状态；包括未选图在内，原则上每张行程图归入一个与主体相符的风貌组。排除状态和归组是独立判断：严重欠曝的路景可以仍归路线组，非行程宣传图可以不归组。**每个实际保留的风貌组都要有至少一张真正能代表它的终选图**；如果没有，先复核是否应与相邻组合并或是否漏看了可用画面，不为凑数硬升劣质图。无法满足时把例外明确交给用户复核。

## 风貌组候选清单

这是一份供城市漫步、建筑参观、历史街区与其他人工环境游览**检索画面主题**的词库，不是必须建立的组，也不是 Chapter Tag。下列名称大多是可调整的示例：同一行里有上位词和更细的候选词，**不应同时照单全建，风貌组名为造词的参考**。只启用素材中确实出现、能凭画面与相邻组区分、且至少有一张适合终选的主题；地点专名须有用户标注、清晰标识或可靠资料支持。

### 街道、巷道与行进空间

| 画面主体    | 可考虑的风貌组名                     | 建组边界                                           |
| ------- | ---------------------------- | ---------------------------------------------- |
| 城市主街    | 城市街景、商业街、步行街、林荫大道、历史街道、滨水街道  | 店铺、招牌和行人通常是同一街道的组成部分；仅当不同街道确有独立地点身份或显著空间差异时拆组。 |
| 支路与窄巷   | 街巷、小巷道、老城巷道、后巷、石板巷道          | “入口”“出口”“转角”通常不另成组；若巷道本身与商业主街明显不同，可分开。         |
| 通行节点    | 繁华的路口、街角、天桥步道、地下通道、桥下通道、沿街骑楼 | 只有路口、阶梯或通道成为主角时单列；仅作为走向下一地点的过渡可归相邻街道组。         |
| 住宅与聚落街面 | 住宅街、老城民居街、村落街巷、庭院外街道、河畔人家    | 按可见建筑形态命名；不能仅凭画面推断居民身份或街道年代。                   |

### 使用这份清单时的取舍

1. **先定 Chapter，再选组名。** Chapter 承担地点与时间连续的路线；风貌组只在章内区别画面主体。不要为了清单里的一个候选名多拆 Chapter，也不要让同一组跨章打乱行程时间。
2. **上位词与细词择一。** “商业街”“沿街店铺”“招牌街景”不是三个必建组；“城市广场”“广场人流”也常是同一组。只有实拍素材显示清楚的主体差异，才细分。
3. **一图按主要观看对象归组。** 河边夜樱、远处晴空塔和游船同框时，判断观众第一眼要看的是什么。塔只是背景就归夜樱步道；塔成为主体，即使只有一张也可单列。
4. **地点名与组名各有任务。** Chapter 标题已经说明地点时，组名可写“滑板场”“商业街”；只有明确街道、设施或水域名称有助于区分时才加专名。具体地名不能靠推测。
5. **终选是保留组的验收条件。** 每个实际风貌组至少有一张能代表它的终选图；如果没有，先合并过细的组或复看素材，不为凑组升选差图。未选与候选仍可归组；片头预览、片尾宣传等非行程画面可不建组。
6. **词库不能穷尽素材，而是造词参考。** 遇到清单未列的建筑、设施或活动，用画面中可证实的名称自拟组名；不要为了贴合清单牺牲准确性。

## 逐图状态与封面

- 并排看相邻帧，比较主体是否清楚、构图和空间层次、地点辨识度、画面信息增量及对路线的作用。**终选**用于独立代表地点、主体、行进转折或稀缺场景；**候选**保留可替换但信息相近的角度；**未选**留给清晰但重复、主题弱或叙事作用小的画面；**排除**用于无关的片头片尾宣传或严重影响理解的画面。无需按组大小、固定间隔或比例选图；相邻两帧若承担不同信息，可以都终选。
- 不因字幕、人物或前景铁网自动排除，也不因画面清晰就自动终选。比较同一鸟居、店铺、街景等近似帧时，保留更能说明主体的一张；普通街景可降为候选，但具有独立地标或活动价值的画面应重新检视。状态、Chapter、风貌组与封面分别记录，互不替代。
- 每章设一张能概括该段**地点与行进空间**的封面，优先在终选中选；若候选画面更适合作封面，保留这一真实选择并复核理由。封面不必是最早一帧，不能只因单家店铺或人物醒目就忽略整章主题。选完后确认封面仍在本章。

## 写入、核验与人工修正

- 续标时先保存当前基线，保留用户已有的章界、组名、图片状态与排序，只补缺漏或改用户明确指出的问题。批量写入前备份数据；通过平台或数据库写入时遵循当前结构，在事务中复查目标记录，避免覆盖用户同时做的调整。注意同一图片的状态可能被多个 Day 共用，章和组关系则按目标 Day 核对。
- 写入后做**全量**核验：来源与总张数；四类状态合计；行程图的 Chapter、风貌组归属及顺序；章间时间无交叉；空组和无终选组；每章封面；Day／Chapter 文案与地点证据；必要时检查标签、备注及数据库一致性。平台页面的“已加载”只是分页数，不代表组内全量。
- Chapter Tag 只使用《Tag 自建库方案》的受控二级词条与标准 `tag_id`，不把视频名、偏移量或未经证实的地点自造为 Tag；图片级标签不因 Chapter 有标签就批量复制。
- 用户修改后，以交付时的逐图表或快照和人工当前快照比较。分别统计**状态改变、图片换章、图片换组、同组改名、组增删、封面和文案变化**；组改名不等于所有组内图片换组。逐图列出 ID、真实时间与前后归属，记录保持不变的项目，再从具体画面归纳可能偏好。只报告快照可证实的结果，不把推断当成用户动机或把单例固化为通用规则。
