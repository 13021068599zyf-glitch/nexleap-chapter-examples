# 自然环境旅程标注

同时维护完整素材的整理结构与少量成片候选。以**当前素材和用户已做的选择**为首要依据；历史样本用于校准判断，不预设任何地点的组名、终选数量或叙事节奏。国家公园徒步、山林、湖泊、海岸、湿地、荒漠和雪地等都可适用；画面中有人、道路或设施，并不使自然旅程失去适用性。

为新的自然素材建组前，读[自然环境风貌组候选清单](references/自然环境风貌组候选清单.md)，把它当作检索索引，再根据实际画面删去未出现、相互重叠或粒度过细的候选名；续标时优先遵循用户已有分组。需要案例时按任务读取：[国家公园 0s 标注习惯](references/国家公园自然风貌（偏移0s）标注习惯总结.md)用于理解徒步与完整旅程；[自然场景筛选策略](references/自然场景筛选逻辑对照与泛化策略.md)用于判断终选的叙事作用；[野花谷 10s、20s 比对日志](references/野花谷自然风貌标注比对日志.md)用于核对人工调整。处理 Chapter 标签时读[Tag 自建库方案](references/Tag自建库方案.md)。

## 组织素材

- 通看整段旅程和相邻抽帧，辨认景观、行进环境、独特事件及出发、转场、收束等节点。不要只凭文件名、固定间隔或单张缩略图判断。
- 按**画面主角或独特事件**建立适合当前素材的风貌组。这里的风貌组是平台的内容整理字段，也可容纳行进或偶遇事件。可从地形、水体、植被、天气、动物和路线场景中辨认主题，但不套用已有案例的组名；背景元素不自动决定归属。组名优先概括可反复辨认的场景，树皮、树洞等局部细节通常写入描述或备注；少量独特画面也可单独成组。
- 用画面证据区分林地、树木和路线：多株树构成的空间归森林风貌，单株树或倒木成为视觉中心归树木主体，小路及其延伸方向成为主体归路线场景。树龄、正在行进、到达或返程等不能仅凭单帧证实的属性，要有连续画面或可靠资料支持；否则使用“林间步道”“林中大树”等可见名称。
- Chapter 按旅程体验划分：连续体验可由一个 Chapter 覆盖；地点、活动或叙事阶段确有明显变化时，可分成多个。风貌组表达主题，可以跨时间出现，不必对应连续时间段。

## 逐帧筛选

- 相似帧并排比较清晰度、主体、构图和信息增量，并问“这张图让观众多理解了什么”。终选可呈现标志景观、空间变化、行进过程、稀缺事件或旅程起讫；候选保留有用的替代视角；重复或作用不突出的画面标未选。相邻帧若承担不同作用，可以同时终选。
- 从全片复核终选集合：既能看见主要环境，也能理解旅程如何推进。高频景色反复出现且信息相近时，可为稀缺的场景或事件让位。不要按组大小、时间间隔或预设比例分配终选；某组也不必为了凑覆盖而强行终选。
- 字幕、人物、道路和设施结合具体画面判断。它们遮挡主体或削弱表达时可降低优先级；提供独特信息或交代旅程时可能增加价值，不自动排除。
- 风貌组回答“画面主要是什么”，状态回答“是否值得进入精简叙述”，备注回答“这一刻在旅程中起什么作用”。三者分开判断；未选图也可以归组，有备注或归入 Chapter 不自动成为终选。三档状态不是逐级流程，复核后可以直接跨档调整。

## 整理与写入

- 开始前核对来源、偏移量、图片总数、已有 Day/Chapter、状态、分组、备注与封面。保留用户已有选择和人工排序；续标时只补缺漏，避免重建或覆盖。
- 除非用户另有要求，完整标注应让每张图都有明确状态及风貌组；少量备注用一句中文交代沿途所见或行进作用。
- Chapter Tag 只取自《Tag 自建库方案》的受控二级词条，保存标准 `tag_id`；不把视频名、精确地点或偏移量自造为 Tag。具体词能确认时不必附加兜底词；身份、关系和个人意义没有证据时留空。图片级标签按用户已有习惯处理，不因为 Chapter 有标签就批量复制。
- 批量写入前备份现有标注数据，使用事务并在写入时复查目标状态，防止覆盖用户同时进行的调整。通过平台 API 或数据库操作时，遵循当前实际数据结构。
- 写入后按**全量**核对状态合计、Chapter 与风貌组归属、终选的主题与旅程节点覆盖、封面、备注和受控标签，并检查数据库一致性。页面“张已加载”是当前分页数量，不等于组内总量；比较人工调整时以全量记录为准。

## 解释调整

以完整记录对照初次标注与手动结果：报告状态和分组逐帧变化、终选重合情况及各组终选分布，同时指出封面、简介、标签、备注等未变化的项目。用具体画面解释可能的取舍依据，把操作事实与偏好推断分开；只把跨素材反复得到支持的偏好提升为通用指引，不替用户断言真实动机。
