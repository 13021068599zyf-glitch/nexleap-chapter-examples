# 自然环境风貌组候选清单

这是一份用于**预测可建组主题**的词库，不是单次旅程必须建立的组，也不是 Chapter Tag。自然环境、拍摄尺度和旅程活动无法被有限清单完全穷尽；以下尽量覆盖常见及较少见的可见画面。实际建组时只启用素材中出现、能与相邻组清楚区分的主题；名称可按具体地点和主体改写。优先使用单帧可辨认的名称；树龄、正在行进、到达或返程等不能仅凭静态画面确定的属性，需要连续画面或可靠资料支持。

| 环境 | 可用的风貌组候选名 |
| --- | --- |
| 森林整体 | 针叶密林、疏林、阔叶林、雨林、竹林、云雾林、红树林、沼泽林、秋色林地、枯木林、森林边缘、林间空地 |

| 草地与灌丛 | 草原、稀树草原、山地草坡、草甸、高山草甸、苔原、低矮灌丛、开花灌木、荒漠植被、湿地草丛 |
| 花卉与低矮植物 | 野花花海、野花近景、单株奇花、花丛与传粉昆虫、季节花开、蕨类群落、蕨叶近景、苔藓近景、露珠草本；物种可以确认时可用物种名细化组名 |
| 菌类与地衣 | 菌类群落、蘑菇近景、地衣近景、腐木菌类；菌类与地衣不是植物，单列以免和花卉、树木混淆 |
| 季节性景观 | 春季新绿、夏季浓荫、秋林彩叶、落叶林地、霜冻草木、雪覆植被、旱季枯黄；只有季节变化成为主要视觉信息时单独建组 |

“森林整体”描述多株树木形成的林相与空间；“树木主体”聚焦一棵树或明确突出的倒木；“花卉与低矮植物”聚焦花、蕨、苔藓等主体；菌类与地衣另列。**分类依据是主要观看对象，不是单纯的拍摄距离**：整片花海即使是全景仍归花卉，一棵突出的树即使在较宽画面中也可归树木。林间光影若成为主角，查下方“光影与倒影”。“古树”涉及树龄，粗大、盘根或空洞只能提示树的形态，不能证明年龄；只有标识牌或可靠资料确认时才使用该名称。

当光线或天气只是其他风貌的氛围，应写进组描述或备注；只有它是主要观看对象时，才考虑以下组名。

| 环境 | 可用的风貌组候选名 |
| --- | --- |
| 天空与天象 | 日出晨光、夕阳余晖、蓝调时刻、星空、银河、月夜、极光、彩虹、云海、翻涌云层 |
| 天气与能见度 | 山间云雾、林间晨雾、湖面薄雾、海雾、雨幕、雪幕、风暴云、雷暴远景、雨后天光、逆光尘雾 |
| 光影与倒影 | 林间光束、山谷光影、波光水面、湖面倒影、雪地反光、峡谷侧光；若倒影中的山或林才是主角，可归相应地貌或植被组 |

## 动物与旅程事件

动物类组名宜随可辨认的物种或具体行为细化，避免把所有偶见动物混入一个笼统组。人类活动只有与自然旅程相关、且在画面中占明显叙事位置时才建组。

| 环境 | 可用的风貌组候选名 |
| --- | --- |
| 陆地动物 | 野生哺乳动物、鹿群穿行、山地兽类、草原兽群、动物足迹、林间觅食、动物亲子；物种可确认时优先用具体名称 |
| 鸟类与昆虫 | 鸟群飞过、猛禽盘旋、湿地水鸟、海鸟栖息、蝴蝶与野花、昆虫访花、蜻蜓临水、萤火虫；小昆虫若仅是背景不必建组 |
| 水生动物 | 河湖鱼群、两栖动物、海洋哺乳动物、潮池生物、珊瑚礁鱼群；以画面可辨认的主体为准 |
| 路线与通行环境 | 林间步道、草甸小径、山地步道、山脊小路、峡谷步道、溪谷步道、湖岸步道、海岸步道、沙地路径、雪地小径、涉水点、倒木横跨溪流；道路或可通行的空间必须是画面主体 |
| 可见行进事件 | 徒步者沿路前行、攀行岩坡、涉水过溪、跨越倒木、驮队经过；人物或动物动作可见，或连续抽帧足以确认行进时才用动作命名 |
| 自然旅程设施 | 木桥、栈道、石阶山路、观景平台、营地、山屋、渡口、登山绳道；只在设施本身或其带来的行进方式成为主体时建组，天然倒木不归人工木桥 |
| 旅程节点与偶遇 | 路径分岔、山口、远望目的地、行经的驮队、遇见野生动物、天气突变；“出发”“到达”“返程”须有连续画面或可靠行程信息支持，不为抽象叙事节点硬建组 |

## 从候选词库选出实际风貌组

1. **先识别素材尺度。** 全景多时以地貌和风貌为主；特写多时可细分花卉、岩纹或小型动物；徒步视角多时可增加行进环境或事件组。不能仅凭目的地名称预设素材一定包含什么。
2. **一张图优先按主要观看对象归组。** 多株树木共同形成林相，归森林风貌；明显的小路及其延伸方向成为主体，归路线场景；一棵树或倒木占视觉中心，归树木主体。草甸小路前景、远山背景可归草甸或草甸小径；山峰占主导时才归远山。天然倒木属于林地或溪谷环境，人工桥梁才归木桥。
3. **控制相邻组的重叠。** “湖泊全景”“湖畔风光”“湖岸浅滩”是备选粒度，素材不足时合并；素材足够且画面作用不同才拆开。其他同义或上下位词也按此处理。
4. **保留少量独特主题。** 一张清楚的驮队、特殊花卉或地热喷气孔，也可能值得单独成组；组的大小与是否终选分开判断。
5. **不要把这份清单当作受控 Tag。** 风貌组按当前画面自拟；Chapter Tag 仍须选自项目的《Tag 自建库方案》并保存标准 `tag_id`。

**林地画面的判别例子：**连续树冠、林下植被和疏密关系占主导，用“针叶密林”等森林风貌；小路在画面中央通向林深处，用“林间步道”；一根横跨小溪的倒木成为主角，用“森林倒木”或更贴合水域的组。仅看到道路，不足以断言拍摄者正在“林间穿行”；可以在可靠的连续旅程信息中描述行进，但单帧组名优先用“林间步道”。
